# LexiCognition - Features Overview

## ✅ What's New & Fixed

### 1. **Removed Role Selection During Login**
- Role is now **auto-detected** from your account
- Students and Teachers login the same way
- Just use your email and password

### 2. **Organized Class Categories**
Registration now has proper categories:
- **🎓 School**: Class 10, 11, 12
- **🏫 BTech**: Year 1, 2, 3, 4
- **🎯 MTech**: Year 1, 2
- **📚 Research**: PhD

### 3. **Teacher Features**

#### Exam Activation with Live Timer
- Click "✅ Activate & Start" to begin exam
- **Live countdown timer** appears (60 minutes default)
- Timer displays in MM:SS format
- Auto-stops when time is up

#### Student Selection with Checkboxes
- Click "👥 Select Students" for any exam
- Students organized by class
- **Checkbox for each student**
- "Select All" option for each class
- Only selected students receive notifications

#### Real-Time Marks Viewing
- Click "📊 View Marks" during or after exam
- See live student progress
- Shows: Name, Class, Status, Score
- Updates automatically as students submit

### 4. **Student Features**

#### Student ID Display
- Your Student ID shown in dashboard header
- Also shows your class (BTech Year 2, etc.)

#### Exam Access
- Only appears if teacher selects you
- Get notification when assigned
- Start exam when ready

---

## 🚀 How to Use

### For Teachers:
1. **Create Exam** → Choose subject, upload PDF
2. **Select Students** → Use checkboxes to choose who can take it
3. **Activate & Start** → Live timer begins
4. **Monitor Live** → Watch student progress in real-time
5. **View Marks** → Detailed results after completion

### For Students:
1. **Check Notifications** → See assigned exams
2. **Start Exam** → Click when ready
3. **Submit** → Teacher sees your score immediately
